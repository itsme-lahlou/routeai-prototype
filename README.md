# RouteAI

**One task. The right model.**

RouteAI is an interactive frontend concept for intelligent multi-model routing. Enter a task to see a simulated recommendation, task profile, model scores, and alternatives. The site includes a routing flow, model comparison, compatibility badges, and a live routing visualization.

This is a university AI + Innovation Design prototype. All model profiles, scores, costs, latency, and benchmark figures are illustrative. It makes no API calls and requires no API keys.

## Run locally

Use Node.js 22 or newer. If you use nvm:

```bash
nvm use
npm install
npm run dev
```

Open the local URL shown by the development server.

## Build

```bash
npm run build
```

Built with React, Vinext/Vite, TypeScript, and CSS.
